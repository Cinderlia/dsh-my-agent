# 刷怪与刷怪塔

## 刷怪条件（原版）

- 亮度 ≤ 7（黑暗）
- 至少有 2 格高的空间
- 距玩家 **24~128 格**（贴着你也刷不出来）
- 方块表面要能站立

## 玩家会这么做

- 把基地周围**点亮**（火把覆盖到 40 格开外）
- 简单刷怪塔：黑暗房间 + 漏斗收集 + 掉落管道

## agent 怎么配合

```
mc_place {name:"torch", mode:"line", length:8}   # 一排火把（照明 = 防刷怪）
mc_collect {name:"coal", count:16}               # 做火把要煤
mc_scan_surroundings {focus:"combat"}            # 雷达看附近有没有敌对
```

## 关键判断

| 现象 | 意思 |
|---|---|
| 附近一直刷怪 | 有黑暗区域没点亮 |
| 刷怪塔效率低 | 玩家离得太远（>128）或太近（<24） |
| 只有蜘蛛 | 天花板有 3 格以上空隙 |

## agent 的自动应对

- **killa** 会自己接管 5 格内的敌对（换武器/跳劈/远离苦力怕）
- 夜晚/黑暗里别乱跑，先点亮再干活
