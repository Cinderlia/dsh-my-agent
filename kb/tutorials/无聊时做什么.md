# 无聊时做什么（Things to do when bored）

> 对应 https://minecraft.wiki/w/Tutorial:Things_to_do_when_bored

## 不无聊的清单

| 类型 | 例子 |
|---|---|
| 建设 | 盖房子、修路、造桥、挖运河 |
| 收藏 | 全物品图鉴、全木材、全花、音乐唱片 |
| 探索 | 找村庄/遗迹/要塞/林地府邸/海底神殿 |
| 挑战 | 不用床活过 100 天、只吃素、不挖矿 |
| 农场 | 自动甘蔗机、刷铁机、村民交易大厅 |
| 红石 | 自动门、电梯、农场 |
| 装饰 | 家具、花园、灯 |

## agent 能做的

```
mc_collect {name:"all_flowers"}          # 不现实，但要收集某几种可以
mc_navi / mc_move                        # 探索
mc_build                                 # 造东西
mc_trade {action:"list"}                 # 逛村民
mc_scan_surroundings {focus:"explore"}   # 找附近有意思的东西
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_trade` —— 作用：村民交易；用法：`{action:"list"}` 先看卖什么，再 `{action:"buy",index}` 按序号买；效果：钱不够或货没了会报
- `mc_scan_surroundings` —— 作用：兴趣点雷达（分层、带方向距离）；用法：`{focus:"build"/"danger"/"ore", r:半径}`；效果：只报值得关注的几类，不是全量方块表
- `mc_move` —— 作用：同步走过去；用法：`{x,y,z}`，或 `{mode:"fly"/"swim"/"boat"}`；效果：最多 11 秒，目标太远会直接说太远
- `mc_navi` —— 作用：异步导航，入队就走、走完主动报告；用法：`{x,y,z}` 或 `{player, follow:true}` 跟人；效果：单次 16 格内本地算路，路被堵自己挖/垫

## 建议

- 记一个"愿望清单"到记忆根（`tasks.md`），无聊时挑一条做
- 大工程先规划：`mc_build` 的 layers 写出来，再备料
  - ↳ 作用：按图批量搭；用法：`{x1,y1,z1,x2,y2,z2,name}` 盖实心盒，或 `blueprint:"layers"` + `layers`/`legend` 分层盖；效果：自己走近+垫脚，每轮最多 10 秒，没盖完把蓝图原样再发一次就接着盖
