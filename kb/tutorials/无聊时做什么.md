# 无聊时做什么（Things to do when bored）

> 对应 https://minecraft.wiki/w/Tutorial:Things_to_do_when_bored

## 不无聊的清单

| 类型 | 例子 |
|---|---|
| 建设 | 盖房子、修路、造桥、挖运河 |
| 收藏 | 全物品图鉴、全木材、全花、音乐唱片 |
| 探索 | 找村庄/遗迹/要塞/林地府邸/海底神殿 |
| 挑战 | 不用床活过 100 天、只吃素、不挖矿 |
| 农场 | 自动甘蔗机、刷铁机、村民交易大厅 |
| 红石 | 自动门、电梯、农场 |
| 装饰 | 家具、花园、灯 |

## agent 能做的

```
mc_collect {name:"all_flowers"}          # 不现实，但要收集某几种可以
mc_navi / mc_move                        # 探索
mc_build                                 # 造东西
mc_trade {action:"list"}                 # 逛村民
mc_scan_surroundings {focus:"explore"}   # 找附近有意思的东西
```

## 建议

- 记一个"愿望清单"到记忆根（`tasks.md`），无聊时挑一条做
- 大工程先规划：`mc_build` 的 layers 写出来，再备料
