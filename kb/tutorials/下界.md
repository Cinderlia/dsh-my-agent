# 下界

## 玩家会这么做

- 黑曜石 10 个 + 打火石 → 传送门（4×5 框架）
- 进下界找**烈焰人**（下界要塞）→ 烈焰棒
- 找**末影人** → 末影珍珠
- 回主世界

## agent 怎么准备

```
mc_probe {what:"prep", args:{for:"nether"}}  # 自查：装备/附魔/食物/黑曜石
mc_collect {name:"obsidian", count:10}       # 黑曜石（钻石镐挖）
mc_craft {name:"flint_and_steel"}            # 打火石
mc_place {mode:"wall", …}                    # 搭传送门框架（或用 mc_build）
```

## 关键数值

| 项 | 数值 |
|---|---|
| 传送门框架 | 4 宽 × 5 高（内部 2×3） |
| 黑曜石 | 10 个 |
| 烈焰棒 | 烈焰人掉，1~2 根 |
| 末影珍珠 | 末影人掉，0~1 个 |

## 危险

- 下界岩浆多、地形窄，**别乱跑**
- 猪灵会攻击没穿金装备的你
- 恶魂会炸传送门
