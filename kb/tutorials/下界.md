# 下界

## 玩家会这么做

- 黑曜石 10 个 + 打火石 → 传送门（4×5 框架）
- 进下界找**烈焰人**（下界要塞）→ 烈焰棒
- 找**末影人** → 末影珍珠
- 回主世界

## agent 怎么准备

```
mc_probe {what:"prep", args:{for:"nether"}}  # 自查：装备/附魔/食物/黑曜石
mc_collect {name:"obsidian", count:10}       # 黑曜石（钻石镐挖）
mc_craft {name:"flint_and_steel"}            # 打火石
mc_place {mode:"wall", …}                    # 搭传送门框架（或用 mc_build）
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_craft` —— 作用：合成 + 熔炼的唯一入口，只说要什么；用法：`{name,count}`；效果：缺料自己插 collect、缺工作台自己找/放/回收，材料凑不齐会明确报失败
- `mc_place` —— 作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了
- `mc_build` —— 作用：按图批量搭；用法：`{x1,y1,z1,x2,y2,z2,name}` 盖实心盒，或 `blueprint:"layers"` + `layers`/`legend` 分层盖；效果：自己走近+垫脚，每轮最多 10 秒，没盖完把蓝图原样再发一次就接着盖
- `mc_probe` —— 作用：偶尔查一次的杂项都从这里进（诊断/背包/方块扫描/任务队列）；用法：`{what:"diag"/"jobs"/"inventory"/"caps", args:{…}}`；效果：按需返回一节，不乱刷屏

## 关键数值

| 项 | 数值 |
|---|---|
| 传送门框架 | 4 宽 × 5 高（内部 2×3） |
| 黑曜石 | 10 个 |
| 烈焰棒 | 烈焰人掉，1~2 根 |
| 末影珍珠 | 末影人掉，0~1 个 |

## 危险

- 下界岩浆多、地形窄，**别乱跑**
- 猪灵会攻击没穿金装备的你
- 恶魂会炸传送门
