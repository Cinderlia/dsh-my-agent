# 起步（第一天）

> 参考：https://minecraft.wiki/w/Tutorials/Your_first_ten_minutes 之类

## 玩家会这么走

1. **撸树**：打 4~8 个原木
2. **工作台**：2×2 做 4 木板 → 工作台
3. **木镐**：3 木板 + 2 木棍
4. **石镐**：挖 3 圆石 → 3 圆石 + 2 木棍
5. **铁**：石镐挖铁矿石 → 熔炉烧成铁锭 → 铁镐/铁剑
6. **庇护所**：天黑前挖个洞/搭个盒子，放床/火把

## agent 怎么走

```
mc_craft {name:"wooden_pickaxe"}     # 一条命令：自己找树/拿原木/做木镐
mc_craft {name:"stone_pickaxe"}      # 缺圆石会自己挖
mc_craft {name:"iron_pickaxe"}       # 缺铁锭→熔炉→挖铁矿→熔炼→合成，全自动
```

**关键**：不要一步步拆，直接要成品就行：

- `mc_craft` —— 作用：合成 + 熔炼的唯一入口，只说要什么；用法：`{name,count}`；效果：缺料自己插 collect、缺工作台自己找/放/回收，材料凑不齐会明确报失败。发一条它就自己找树、做工作台、烧铁、最后做出铁镐。

## 关键数值

| 事 | 数值 |
|---|---|
| 木镐能挖 | 石头/圆石/煤 |
| 石镐能挖 | 铁矿石/金矿石/钻石（钻石要铁镐） |
| 铁矿石 → 铁锭 | 1 个烧 10 秒 |
| 天黑 | time > 13000 |

## 工具接口

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_place` —— 作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了
- `mc_act` —— 作用：成系列的动作（收菜/睡觉/吃东西…）；用法：`{mode:"farm"}`；效果：只收熟的、收完补种，夜里才能睡
