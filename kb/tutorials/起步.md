# 起步（第一天）

> 参考：https://minecraft.wiki/w/Tutorials/Your_first_ten_minutes 之类

## 玩家会这么走

1. **撸树**：打 4~8 个原木
2. **工作台**：2×2 做 4 木板 → 工作台
3. **木镐**：3 木板 + 2 木棍
4. **石镐**：挖 3 圆石 → 3 圆石 + 2 木棍
5. **铁**：石镐挖铁矿石 → 熔炉烧成铁锭 → 铁镐/铁剑
6. **庇护所**：天黑前挖个洞/搭个盒子，放床/火把

## agent 怎么走

```
mc_craft {name:"wooden_pickaxe"}     # 一条命令：自己找树/拿原木/做木镐
mc_craft {name:"stone_pickaxe"}      # 缺圆石会自己挖
mc_craft {name:"iron_pickaxe"}       # 缺铁锭→熔炉→挖铁矿→熔炼→合成，全自动
```

**关键**：不要一步步拆。`mc_craft {name:"iron_pickaxe"}` 会把整条链走完
（缺工作台找/放、缺铁锭烧、缺矿石挖、没镐子先做木镐）。

## 关键数值

| 事 | 数值 |
|---|---|
| 木镐能挖 | 石头/圆石/煤 |
| 石镐能挖 | 铁矿石/金矿石/钻石（钻石要铁镐） |
| 铁矿石 → 铁锭 | 1 个烧 10 秒 |
| 天黑 | time > 13000 |

## 工具

- 合成：`mc_craft`
- 采集：`mc_collect {name, count}`
- 放工作台：`mc_place` / `mc_craft` 自动
- 睡觉：`mc_act {mode:"sleep"}`
