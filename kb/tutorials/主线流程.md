# 完整主线冒险（Complete main adventure）

> 对应 https://minecraft.wiki/w/Tutorial:Complete_main_adventure

## 主线顺序

```
1. 木 → 石 → 铁装备
2. 食物（农场/打猎）
3. 附魔台 + 15 书架
4. 钻石装备
5. 下界：烈焰棒（烈焰人）+ 末影珍珠（末影人）
6. 末影之眼 ×12 → 找要塞
7. 进末地 → 拆水晶 → 打龙
8. 拿龙蛋 / 进末地城
```

## 每步 agent 怎么走

| 阶段 | 命令 |
|---|---|
| 铁装备 | `mc_craft {name:"iron_pickaxe"}` / `{name:"iron_sword"}` |
| 食物 | `mc_collect {name:"wheat"}` / `mc_interact {action:"breed"}` |
| 附魔 | `mc_station {kind:"enchant", option:2}` |
| 下界 | `mc_probe {what:"prep", args:{for:"nether"}}` → 备黑曜石/打火石 |
| 要塞 | `mc_collect {name:"ender_eye", count:12}` |
| 末地 | `mc_probe {what:"prep", args:{for:"end"}}` → `mc_shoot {who:"ender_dragon"}` |

- `mc_craft` —— 作用：合成 + 熔炼的唯一入口，只说要什么；用法：`{name,count}`；效果：缺料自己插 collect、缺工作台自己找/放/回收，材料凑不齐会明确报失败
- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_interact` —— 作用：通用右键交互（上船/锄地/播种/繁殖/剪羊毛/挤奶/开关门）；用法：`{action:"plant"}` 之类；效果：自动换对该用的东西再动手，目标没找到会直说
- `mc_station` —— 作用：对着方块开界面操作（附魔台/铁砧/锻造台）；用法：`{kind:"enchant",…}`；效果：走到方块、打开界面、按你说的点，等级或材料不够会报
- `mc_probe` —— 作用：偶尔查一次的杂项都从这里进（诊断/背包/方块扫描/任务队列）；用法：`{what:"diag"/"jobs"/"inventory"/"caps", args:{…}}`；效果：按需返回一节，不乱刷屏
- `mc_shoot` —— 作用：射箭；用法：`{who:"zombie"}` 或 `{x,y,z}`；效果：自动换弓、算弹道、拉满再放，射完报身边还有谁

## 关键数值

| 项 | 数值 |
|---|---|
| 钻石层 | y=-59~-64 最多 |
| 末影之眼 | 12 个（要塞框架） |
| 烈焰棒 | 2~3 根（做末影之眼要烈焰粉） |
| 末影珍珠 | 12~16 个 |

## 提醒

- 每一步都先 `mc_probe {what:"prep"}` 自查再出发
- 打龙前先拆水晶，别贴脸
- 死了掉全套：**先去捡**（5 分钟内）
