# 完整主线冒险（Complete main adventure）

> 对应 https://minecraft.wiki/w/Tutorial:Complete_main_adventure

## 主线顺序

```
1. 木 → 石 → 铁装备
2. 食物（农场/打猎）
3. 附魔台 + 15 书架
4. 钻石装备
5. 下界：烈焰棒（烈焰人）+ 末影珍珠（末影人）
6. 末影之眼 ×12 → 找要塞
7. 进末地 → 拆水晶 → 打龙
8. 拿龙蛋 / 进末地城
```

## 每步 agent 怎么走

| 阶段 | 命令 |
|---|---|
| 铁装备 | `mc_craft {name:"iron_pickaxe"}` / `{name:"iron_sword"}` |
| 食物 | `mc_collect {name:"wheat"}` / `mc_interact {action:"breed"}` |
| 附魔 | `mc_station {kind:"enchant", option:2}` |
| 下界 | `mc_probe {what:"prep", args:{for:"nether"}}` → 备黑曜石/打火石 |
| 要塞 | `mc_collect {name:"ender_eye", count:12}` |
| 末地 | `mc_probe {what:"prep", args:{for:"end"}}` → `mc_shoot {who:"ender_dragon"}` |

## 关键数值

| 项 | 数值 |
|---|---|
| 钻石层 | y=-59~-64 最多 |
| 末影之眼 | 12 个（要塞框架） |
| 烈焰棒 | 2~3 根（做末影之眼要烈焰粉） |
| 末影珍珠 | 12~16 个 |

## 提醒

- 每一步都先 `mc_probe {what:"prep"}` 自查再出发
- 打龙前先拆水晶，别贴脸
- 死了掉全套：**先去捡**（5 分钟内）
