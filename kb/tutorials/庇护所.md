# 庇护所（Shelters）

> 对应 https://minecraft.wiki/w/Tutorial:Shelters

## 要点

- **第一天不用盖好房**：挖山洞、垫高两格、封个洞都算庇护所
- 选址：离水源近、地势平、别在沼泽/沙漠（晚上刷怪多）
- 常见类型：地洞 / 树屋 / 山顶小屋 / 水下屋 / 村庄借住
- 门要**正对安全方向**；窗户别太大（苦力怕/骷髅能看见你）

## agent 怎么建

```
mc_build {layers:["BBB/BBB/BBB", …], legend:{B:"oak_planks"}}   # 按图施工（先拆挡路的再放）
mc_place {mode:"wall", …}                                      # 批量一面墙
mc_place {mode:"volume", …}                                    # 实心盒子
mc_collect {name:"oak_log", count:32}                          # 备料
mc_interact {action:"open"}                                    # 装门后开关门
```

- `mc_interact` —— 作用：通用右键交互（上船/锄地/播种/繁殖/剪羊毛/挤奶/开关门）；用法：`{action:"plant"}` 之类；效果：自动换对该用的东西再动手，目标没找到会直说

**建议顺序**：先 `mc_collect`（作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败） 备料 → `mc_build`（作用：按图批量搭；用法：`{x1,y1,z1,x2,y2,z2,name}` 盖实心盒，或 `blueprint:"layers"` + `layers`/`legend` 分层盖；效果：自己走近+垫脚，每轮最多 10 秒，没盖完把蓝图原样再发一次就接着盖） 主体 → `mc_place`（作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了） 补屋顶/地板 → `mc_place` 放门/火把。

## 尺寸参考

| 房间 | 尺寸 |
|---|---|
| 单人小屋 | 7×7 内部，3 高 |
| 带阁楼 | 9×7，两层 |
| 挖山洞 | 至少 5×5×3 |

## 关键

- **先围起来再装修**（防怪）
- 火把/灯笼：每 5~7 格一个
- 床放好 → 设重生点
