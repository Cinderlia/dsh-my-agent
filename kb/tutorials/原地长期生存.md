# 原地长期生存（Surviving in a single area for a long time）

> 对应 https://minecraft.wiki/w/Tutorial:Surviving_in_a_single_area_for_a_long_time

## 核心思路

不跑远路，把**一个区域**吃干榨净：

- **树场**：种树 → 砍 → 再种（可持续木头）
- **农田**：小麦 + 动物（食物自给）
- **矿道**：一条主矿道往下/往远，支线挖矿石
- **刷铁机/刷怪塔**：铁和掉落物
- **村民**：交易换稀缺资源

## 可持续循环

```
树 → 木板 → 工具/建筑
小麦 → 面包/喂动物
动物 → 肉/皮革/羊毛
矿道 → 石头/矿石
村民 → 换东西
```

## agent 怎么做

```
mc_collect {name:"oak_log", count:64}          # 伐木（会补种吗？不会，记得自己种）
mc_interact {action:"plant"}                    # 补种树苗
mc_act {mode:"farm", count:16}                  # 收田+补种
mc_interact {action:"breed", who:"cow"}         # 扩栏
mc_dig {mode:"line", dir:"west", length:16}     # 主矿道
mc_trade {action:"list"}                        # 村民
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_dig` —— 作用：挖方块；用法：`{name}` 挖最近的或 `{x,y,z}` 挖指定格，`count` 连挖几个；效果：自动换对工具、超 4.2 格自己走过去，挖下来的东西要再用 collect 收
- `mc_interact` —— 作用：通用右键交互（上船/锄地/播种/繁殖/剪羊毛/挤奶/开关门）；用法：`{action:"plant"}` 之类；效果：自动换对该用的东西再动手，目标没找到会直说
- `mc_act` —— 作用：成系列的动作（收菜/睡觉/吃东西…）；用法：`{mode:"farm"}`；效果：只收熟的、收完补种，夜里才能睡
- `mc_trade` —— 作用：村民交易；用法：`{action:"list"}` 先看卖什么，再 `{action:"buy",index}` 按序号买；效果：钱不够或货没了会报

## 关键

- **补给线**：别把家建在离资源太远的地方
- **储备**：至少一箱食物、一箱木头、半箱铁
- **照明**：整片区域点亮（防刷怪）
- 定期 `mc_chest {action:"open"}` 盘点库存
  - ↳ 作用：开箱子存取东西；用法：先 `{action:"open"}` 看里面有什么，再 `{action:"take"/"put",items:[…]}`；效果：一趟只办一件事，容量不够会报
