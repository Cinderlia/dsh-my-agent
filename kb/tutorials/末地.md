# 末地

## 玩家会这么做

1. 找**要塞**（末影之眼定位）
2. 12 个末地传送门框架 + 12 个末影之眼
3. 进末地 → 打末影龙（先拆水晶）
4. 打完跳返回传送门

## agent 怎么准备

```
mc_probe {what:"prep", args:{for:"end"}}   # 自查：末影之眼/装备/食物
mc_collect {name:"ender_pearl", count:12}  # 末影珍珠
mc_craft {name:"ender_eye", count:12}      # 珍珠 + 烈焰粉
mc_shoot {who:"ender_dragon"}              # 打龙（自动瞄 +2.8）
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_craft` —— 作用：合成 + 熔炼的唯一入口，只说要什么；用法：`{name,count}`；效果：缺料自己插 collect、缺工作台自己找/放/回收，材料凑不齐会明确报失败
- `mc_shoot` —— 作用：射箭；用法：`{who:"zombie"}` 或 `{x,y,z}`；效果：自动换弓、算弹道、拉满再放，射完报身边还有谁
- `mc_probe` —— 作用：偶尔查一次的杂项都从这里进（诊断/背包/方块扫描/任务队列）；用法：`{what:"diag"/"jobs"/"inventory"/"caps", args:{…}}`；效果：按需返回一节，不乱刷屏

## 关键数值

| 项 | 数值 |
|---|---|
| 末地传送门 | 12 框架 + 12 眼睛 |
| 末影龙 | 200 血，先拆 4 个水晶 |
| 返回 | 跳进返回传送门 |

## 危险

- 末地虚空：掉下去就没了
- 水晶爆炸：别贴脸
- 龙息/俯冲：躲柱子后面
