# 末地

## 玩家会这么做

1. 找**要塞**（末影之眼定位）
2. 12 个末地传送门框架 + 12 个末影之眼
3. 进末地 → 打末影龙（先拆水晶）
4. 打完跳返回传送门

## agent 怎么准备

```
mc_probe {what:"prep", args:{for:"end"}}   # 自查：末影之眼/装备/食物
mc_collect {name:"ender_pearl", count:12}  # 末影珍珠
mc_craft {name:"ender_eye", count:12}      # 珍珠 + 烈焰粉
mc_shoot {who:"ender_dragon"}              # 打龙（自动瞄 +2.8）
```

## 关键数值

| 项 | 数值 |
|---|---|
| 末地传送门 | 12 框架 + 12 眼睛 |
| 末影龙 | 200 血，先拆 4 个水晶 |
| 返回 | 跳进返回传送门 |

## 危险

- 末地虚空：掉下去就没了
- 水晶爆炸：别贴脸
- 龙息/俯冲：躲柱子后面
