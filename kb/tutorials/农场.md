# 农场（小麦/动物）

## 玩家会这么做

- 锄头锄地 → 种子种下 → 旁边 4 格内有水 → 等成熟（age=7）收
- 收完**立刻补种**
- 动物：围栏 + 两只同类 + 喂食物 → 繁殖

## agent 怎么种

```
mc_interact {action:"hoe", x,y,z}        # 锄一格（自动换锄头）
mc_interact {action:"plant", x,y,z}      # 种一格（自动换种子）
mc_act {mode:"farm", count:8}            # 批量：只收熟的、收完补种
mc_collect {name:"wheat", count:8}       # 收集小麦
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_interact` —— 作用：通用右键交互（上船/锄地/播种/繁殖/剪羊毛/挤奶/开关门）；用法：`{action:"plant"}` 之类；效果：自动换对该用的东西再动手，目标没找到会直说
- `mc_act` —— 作用：成系列的动作（收菜/睡觉/吃东西…）；用法：`{mode:"farm"}`；效果：只收熟的、收完补种，夜里才能睡

## agent 怎么养

```
mc_interact {action:"breed", who:"cow"}  # 自动选小麦，对两只各喂一次
mc_interact {action:"shear"}             # 剪羊毛
mc_interact {action:"milk"}              # 挤奶（空桶）
```

## 关键数值

| 作物 | 成熟时间 | 繁殖食物 |
|---|---|---|
| 小麦 | 7 阶段，要水 | 牛/羊 吃小麦 |
| 胡萝卜/马铃薯 | 8 阶段 | 猪 吃胡萝卜/马铃薯 |
| 甜菜根 | 4 阶段 | 猪 吃甜菜根 |

## 水田要求

每格农田**水平 4 格内**要有一格水（或湿润 farmland），否则会干。
