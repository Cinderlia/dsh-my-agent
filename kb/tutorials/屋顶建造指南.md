# 屋顶建造指南（Roof construction guidelines）

> 对应 https://minecraft.wiki/w/Tutorial:Roof_construction_guidelines

## 原则

1. **先定宽度再定形状**：屋顶宽度决定坡度
2. **外扩 1 格**：比墙多出一圈（防雨、有层次）
3. **楼梯优先**：斜面用楼梯/半砖，比完整方块自然
4. **不同材质**：屋脊/屋檐/主体用不同颜色
5. **别封死**：留天窗、烟囱、阁楼入口

## 尺寸公式（双坡）

```
脊高 = ceil(宽度 / 2)
每层内收 1 格
屋檐外扩 1 格
```

例：7 宽双坡 → 脊高 4，5 层（含屋檐）。

## agent 的施工顺序

```
1. mc_collect {name:"oak_stairs", count:64}    # 备料（或用 craft 转换）
2. mc_build {layers:[…], legend:{S:"oak_stairs"}}  # 主体
3. mc_place {mode:"line"}                       # 屋檐一圈
4. mc_scan_surroundings {focus:"build"}          # 看看还缺什么
```

- `mc_collect` —— 作用：自动采集某样东西——找来源、走过去挖/打、把掉落物捡回来；用法：`{name,count}`；效果：东西真进背包才算数，附近的目标都挖光了就报失败
- `mc_place` —— 作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了
- `mc_build` —— 作用：按图批量搭；用法：`{x1,y1,z1,x2,y2,z2,name}` 盖实心盒，或 `blueprint:"layers"` + `layers`/`legend` 分层盖；效果：自己走近+垫脚，每轮最多 10 秒，没盖完把蓝图原样再发一次就接着盖
- `mc_scan_surroundings` —— 作用：兴趣点雷达（分层、带方向距离）；用法：`{focus:"build"/"danger"/"ore", r:半径}`；效果：只报值得关注的几类，不是全量方块表

## 常见错误

| 错误 | 结果 |
|---|---|
| 坡度太陡 | 看着突兀，还容易踩空 |
| 没外扩 | 雨水直接流到墙上，视觉上"贴墙" |
| 全是同一种方块 | 单调，没有层次 |
| 留了洞没封 | 里面刷怪 |

## 提醒

- 屋顶是**装饰**，别花太多时间在第一天
- 先保证能住，再慢慢改
