# 家具（Furniture）

> 对应 https://minecraft.wiki/w/Tutorial:Furniture

## 要点（都是"用方块拼出来"）

| 家具 | 怎么拼 |
|---|---|
| 椅子 | 楼梯 + 告示牌靠背 |
| 桌子 | 栅栏 + 压力板 / 活板门 |
| 床 | 两格羊毛 + 木板 |
| 书架 | 木板 + 书（装饰用，也是附魔燃料） |
| 灯 | 灯笼挂栅栏 / 海晶灯 / 南瓜灯 |
| 花盆 | 花盆 + 花 |
| 地毯 | 两格羊毛 |
| 箱子堆 | 箱子 + 陷阱箱（外观一样） |

## agent 怎么放

```
mc_place {mode:"line", name:"oak_stairs", length:3}     # 一排楼梯当椅子
mc_place {x,y,z, name:"oak_fence"}                      # 桌腿
mc_place {x,y,z, name:"oak_pressure_plate"}             # 桌面
mc_interact {action:"open"}                             # 开箱子/门
```

- `mc_place` —— 作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了
- `mc_interact` —— 作用：通用右键交互（上船/锄地/播种/繁殖/剪羊毛/挤奶/开关门）；用法：`{action:"plant"}` 之类；效果：自动换对该用的东西再动手，目标没找到会直说

## 提醒

- 家具**没有功能**（除了床/箱子/工作台），别为它们花太多材料
- 告示牌可以写字（`mc_act {mode:"useitem"}` 后输入，或直接放）
  - ↳ 作用：成系列的动作（收菜/睡觉/吃东西…）；用法：`{mode:"farm"}`；效果：只收熟的、收完补种，夜里才能睡
- 花盆要放在**完整方块**上
