# 附魔

## 玩家会这么做

- 做附魔台（4 黑曜石 + 2 钻石 + 1 书）
- 周围摆 **15 个书架**（间隔 1 格）→ 30 级附魔
- 攒青金石（每级 1 个，30 级要 3 个）
- 经验：挖矿/打怪/烧东西

## agent 怎么操作

```
mc_station {kind:"enchant", option:2}     # 走到附魔台，选第 3 项（30 级）
mc_collect {name:"lapis_lazuli", count:3} # 青金石
mc_probe {what:"prep", args:{for:"nether"}} # 出发前自查（装备/附魔/等级）
```

## 关键数值

| 项 | 数值 |
|---|---|
| 30 级附魔 | 需要 15 书架 + 30 级 + 3 青金石 |
| 书架范围 | 附魔台周围 2 格，高度 0~1 |
| 经验等级 | 打怪/挖矿/烧炼 |

## 注意

- 附魔台和书架之间**不能有方块挡着**
- 等级不够时先别急着附魔（浪费青金石）
