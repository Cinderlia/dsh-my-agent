# 建筑美化（Adding beauty to constructions）

> 对应 https://minecraft.wiki/w/Tutorial:Adding_beauty_to_constructions

## 六个手法

1. **配色**：主色 + 对比色（深色木头配浅色石头）
2. **层次**：墙外凸一圈（勒脚）、屋顶外扩、柱子
3. **细节**：窗框、门框、花盆、灯笼、旗帜
4. **不规则**：别全是正方形，加个凸出的小房间
5. **材质混搭**：圆石 + 石砖 + 苔石砖（自然过渡）
6. **光照**：灯笼/海晶灯/萤石，晚上好看

## 配色参考

| 主题 | 主色 | 点缀 |
|---|---|---|
| 乡村小屋 | 橡木/云杉 | 石砖、干草 |
| 沙漠 | 砂岩/红砂岩 | 陶瓦 |
| 森林 | 深色橡木 | 苔石、藤蔓 |
| 现代 | 白混凝土 | 玻璃、石英 |

## agent 怎么做

```
mc_place {name:"oak_log", mode:"line"}        # 柱子
mc_place {name:"cobblestone", mode:"wall"}    # 勒脚
mc_place {name:"lantern"}                      # 灯
mc_place {x,y,z, name:"flower_pot"}            # 细节
```

## 提醒

- **先结构后装饰**：别在没墙的时候摆花盆
- 一次只改一小块，`mc_observe` 看一眼再继续
- 材料不够就先 `mc_collect`，别边建边缺
