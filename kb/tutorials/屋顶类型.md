# 屋顶类型（Roof types）

> 对应 https://minecraft.wiki/w/Tutorial:Roof_types

## 常见类型

| 类型 | 形状 | 适合 |
|---|---|---|
| 平顶 | 平的 + 栏杆 | 现代/沙漠 |
| 单坡 | 一边高一边低 | 附属建筑 |
| 双坡（人字） | 中间脊，两边斜 | 最常见的小屋 |
| 四坡 | 四面斜向中心 | 方形建筑 |
| 尖顶 | 高耸的三角形 | 塔楼/教堂 |
| 圆顶 | 圆弧 | 大型建筑 |

## 双坡屋顶的尺寸（最常用）

- 屋脊高度 = 半宽 + 1（比如 7 宽 → 脊高 4）
- 每层向内收 1 格
- 用**楼梯方块**做斜面（比用完整方块好看）

## agent 怎么建

```
# 逐层向内收的写法（7 宽为例，从下往上）
mc_build {layers:[
  "SSSSSSS",
  "SSSSSSS",
  ".SSSSS.",
  "..SSS..",
  "...S...",
], legend:{S:"oak_stairs"}}
```

- `mc_build` —— 作用：按图批量搭；用法：`{x1,y1,z1,x2,y2,z2,name}` 盖实心盒，或 `blueprint:"layers"` + `layers`/`legend` 分层盖；效果：自己走近+垫脚，每轮最多 10 秒，没盖完把蓝图原样再发一次就接着盖

或者用 `mc_place {mode:"line"}`（作用：放方块；用法：`{x,y,z,name}`，或 `mode:"wall"/"volume"` + 范围；效果：悬空会先垫脚，放完报放了几块、被谁挡了） 一层层铺。

## 提醒

- 屋顶要比墙**外扩 1 格**（防雨/好看）
- 用不同材质做屋脊（对比色）
- 留天窗/烟囱位置
