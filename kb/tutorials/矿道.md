# 矿道与挖矿

## 玩家会这么做

- 主矿道 2 格高、1 格宽，**每 2 格插火把**（防刷怪）
- 遇到岩浆：绕开，别去够旁边的矿
- 铁在 y=-24~56，钻石在 y=-59~-64 附近最多
- 一路放梯子/水桶上下

## agent 怎么挖

```
mc_collect {name:"iron_ore", count:8}      # 自动找矿、换镐、挖、捡、计数
mc_dig {mode:"column", depth:3}            # 挖一列（往下）
mc_dig {mode:"line", dir:"east", length:8} # 挖一条矿道
mc_map {mode:"column", target:"x,z"}       # 跑远路前先看那一列地表 y
```

## 关键规则

| 规则 | 工具 |
|---|---|
| 挖前换对工具 | 自动（`collect`/`dig` 会检查 harvestTools） |
| 没有镐子 | 自动插 craft 补（木→石；铁锭以上不自动收集） |
| 脚下悬空 | `mc_dig` 默认拦（`allowDangerous:true` 才挖） |
| 岩浆 | 只警告，不靠近 |
| 掉落物 | 挖完等吸附，捡不到才插一次导航 |

## 坑

- **铁矿石要石镐以上**，木镐挖了不掉 —— 工具会自动判断并在缺镐时先做。
- **深层挖到基岩**：`column` 模式会在基岩处失败，属正常。
